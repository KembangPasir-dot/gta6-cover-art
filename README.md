An offline web application that turns your photos and captions into GTA 6-style multi-panel cover art featuring Vice City sunset grades, multi-panel poster layouts, crop/pan/zoom, and bold OFL typography (Anton & Archivo Black).

## How to Run

```bash
node serve.ts
```

Then open `http://localhost:8080` in your browser.

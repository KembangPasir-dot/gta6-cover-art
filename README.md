VICE COVER turns photos and captions into GTA 6-style cover art offline. The Stage 7 rework pairs people covers and a golden-hour grade with original titles, clearer spacing for the poster furniture, and Yellowtail script subtitles. Anton and Archivo Black are bundled under the SIL Open Font License 1.1; Yellowtail is bundled under Apache License 2.0.

## How to Run

```bash
node serve.ts
```

Then open `http://localhost:8080` in your browser.
